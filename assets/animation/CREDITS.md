# Rights and credits

캐릭터·장치·표정은 KICE Arena contributors가 제작했으며 이 저장소의 MIT 라이선스를 따릅니다. 원본 SVG와 JSON 장면·모션 데이터를 함께 제공합니다.

7개 기본 모션은 CMU Graphics Lab의 모션 캡처를 현재 캐릭터에 맞게 투영·리타게팅한 데이터입니다. 나머지는 작성한 안무입니다.

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

- [CMU 사용 조건](https://mocap.cs.cmu.edu/faqs.php): 캡처 데이터의 복사·수정·재배포 허용.
- [Bruce Hahne의 BVH 변환](https://sites.google.com/a/cgspeed.com/cgspeed/motion-capture/the-motionbuilder-friendly-bvh-conversion-release-of-cmus-motion-capture-database): 추가 제한 없음.
- 원본 파일16_15,09_01,16_01,13_26,13_33의 선택 구간·해시는 `character.json`의 각 모션 `source`에 기록되어 있습니다.

브라우저 재생기는 외부 라이브러리나 네트워크 서비스에 의존하지 않습니다. CMU 원본 BVH는 패키지에 포함하지 않았으며, 선택 프레임의 리타게팅 관절 포즈·입력 파일 해시·클립 출처가 `character.json`에 기록되어 있습니다. 수학 기호는 SVG text이며 기본 Georgia/serif 대체 글꼴을 사용합니다. PNG는 제작 시점의 고해상도 렌더를 제공합니다.
